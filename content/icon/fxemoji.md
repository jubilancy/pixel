How do I download Firefox OS Emoji SVG icons?

Click any icon in the browser above to open the detail panel. Choose raw SVG code to copy, download as SVG or PNG, export as a React JSX component, or get a Base64 data URI, all formats free, no sign-up required.

How many icons are in Firefox OS Emoji?

Firefox OS Emoji contains 1,034 SVG icons in the Emoji category, designed on a 32px grid.

Are Firefox OS Emoji icons full-color or monochrome?

Firefox OS Emoji icons are multi-color: they include built-in color information and do not need a fill or stroke applied. They render as-is without inheriting CSS currentColor.

Is Firefox OS Emoji organized into categories?

Yes. Firefox OS Emoji is split into 6 categories including Flags, Nature, Objects, People and 2 more. Use the category tabs in the browser above to filter.

Which icon collections include Firefox OS Emoji?
